# 🌲 DIALED — YOUR BIKE. YOUR BUILD. YOUR PROGRESSION.

hey! welcome to **Dialed** :D

Dialed is a mountain biking platform designed to bring bike maintenance, component tracking, and virtual bike building together in one place.

the goal is to create a platform where mountain bikers can manage their real bikes, track maintenance, customize their dream builds, and progress through an unlockable component system.

basically, everything mountain biking in one place.

##  FEATURES

### REAL GARAGE
- register and manage your real mountain bikes
- track components installed on your bikes
- record maintenance and service history
- monitor component wear and service intervals
- save bike settings and configurations

### DREAM GARAGE
- create and customize virtual mountain bikes
- build bikes using real-world component brands
- collect and purchase virtual components
- move owned components between different dream bikes
- unlock higher-end components as you level up

### PROGRESSION
- earn XP and coins
- unlock new brands and components
- expand your dream bike collection
- customize your builds

##  HOW TO RUN THE PROJECT

### 1. Clone the repository

```sh
git clone YOUR_GITHUB_REPOSITORY_URL
```

### 2. Navigate into the project folder

```sh
cd Dialed
```

### 3. Install dependencies

```sh
python -m pip install fastapi uvicorn
```

### 4. Start the development server

```sh
python -m uvicorn main:app --reload
```

### 5. Open Dialed

Visit:

http://127.0.0.1:8000

You can also access the interactive API documentation at:

http://127.0.0.1:8000/docs
