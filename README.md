# DIALED
#CURRENT PHASE
##PHASE-1
**Your mountain bike. Your maintenance. All dialed in.**

DIALED is a mountain biking garage and maintenance platform designed to help riders manage their bikes, track component wear, record maintenance, and customize their dream builds.

The goal is to give mountain bikers one place to keep track of everything happening with their equipment.

## Features

### Overview
A central dashboard displaying bike statistics, builds, and maintenance activity.

### My Bikes
A personal garage where riders can manage their bikes and view their specifications.

### Bike Builder
A customization area where riders can create and experiment with dream bike builds.

### Maintenance
A maintenance tracking system designed to help riders:
- Keep track of upcoming service.
- Monitor component condition and wear.
- Log completed maintenance.
- Attach photos as maintenance records.
- Review service history.

### Profile
A personal rider profile featuring riding statistics, progression, and achievements.

## Technology Stack

- **HTML** — Page structure
- **CSS** — Styling and layout
- **Python** — Backend development
- **FastAPI** — Backend framework

## Design

DIALED uses a dark, earthy visual style inspired by mountain biking and the Pacific Northwest.

The interface focuses on:
- Deep forest greens
- Warm off-white text
- Muted natural colors
- Minimalist layouts
- Clean, organized components
